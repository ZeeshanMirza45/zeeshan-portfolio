# Zeeshan Zahid Portfolio

Premium responsive Next.js portfolio inspired by the supplied reference.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production
```bash
npm run build
npm start
```

## Assets
- `public/profile-hero.png` — hero portrait
- `public/office-photo.png` — office portrait
- `public/resume.pdf` — CV

Replace the CSS project artwork with real screenshots in `src/components/Portfolio.tsx` when desired.
